## Selected work

### AWS application platform
Designed a secure, highly available AWS environment for a .NET, Angular, and MSSQL application. The platform uses separate Dev, Staging, UAT, and Production environments, EC2 Auto Scaling, an Application Load Balancer, infrastructure as code, managed secrets, and a database replication and disaster-recovery strategy.

### Compliance and security
Helped deliver SOC 2 Type I and Type II compliance for a Python, Angular, and PostgreSQL platform. Implemented infrastructure and organizational controls covering access, encryption, logging, vulnerability remediation, hardening, and business continuity. Also contributed to HIPAA-aligned healthcare infrastructure and safeguards for protected health information.

### AI bot integrations
Integrated Amazon Bedrock with Anthropic models and deployed local language models with Ollama. Built a multi-model integration layer with model switching and secure API interactions, then automated deployment for production use.

### Cloud reliability
Built and operated workloads across AWS virtual machines, ECS, K3s, and EKS. Applied network isolation, IAM hardening, monitoring, multi-AZ design, automated failover, and backup and restore strategies.
